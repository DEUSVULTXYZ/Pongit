# PONGIT logo proposals

Generated with the built-in `image_gen.imagegen` tool. Three independent square 3D renders were created, then converted to WebP and resized for static web use with Sharp. No 3D renderer runs during a game. The favicon SVG is a code-drawn simplification of the orbital silhouette.

1. **Opposing Orbits** — main identity: `web/public/brand/opposing-orbits.webp`, with `avatar.webp`, `web/app/icon.png` and `web/app/icon.svg` variants.
2. **Rebound Ribbon** — `web/public/brand/rebound-ribbon.webp`.
3. **Fractured Core** — `web/public/brand/fractured-core.webp`.

The generated compositions use a near-black background. The avatar variant is square and can be clipped by its display container.

Shared prompt:

> Use case: logo-brand. New PONGIT arcade game logo, premium abstract 3D sculpture, not literal paddles, no letters, no text, no watermark. Centered square composition with generous clear margin, dark near-black background #050505. Translucent glass material, cyan and violet neon refractions, clean silhouette readable at small size, polished dimensional render, restrained bloom, no extraneous scenery.

Directions supplied separately: two opposing thick orbital curves around a luminous white core; a continuous folded ribbon expressing rebound; and a fragmented faceted core with light between its pieces. The primary follows the first direction selected in the implementation brief.
