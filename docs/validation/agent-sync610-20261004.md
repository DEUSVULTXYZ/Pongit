## Corrections

Candidate `41101a3` fixes two browser-side scheduling defects:

1. Periodic synchronization saw an ordinary in-flight command in the nonce
   journal and queued full recovery unconditionally. It now joins that command
   and rechecks uncertainty at the serialized boundary. A confirmed command
   preserves its sender, nonce and prediction. A genuinely lost response still
   enters the existing reconciliation path.
2. The heartbeat loop dropped timer ticks while awaiting a receipt and its
   required snapshot read. A 400 ms command/read could then wait until 600 ms
   to start the next pulse, exceeding the contract's 500 ms credit. Missed
   ticks now coalesce into one immediate follow-up after success. Visibility,
   fresh perception, stop behavior and one command in flight remain required.

The in-flight synchronization regression failed on the prior code (two binding
handshakes instead of one) and passes with the fix. Fifty-four focused tests
and root TypeScript pass. The full TypeScript run is **990/991**, not a full
pass: the unchanged rating-continuation audit rejects the current local compiled
`ContinuingAgentRatings` artifact hash. No rating source, audit allowlist or
contract artifact was changed to silence that failure.
