# Pixel Palace artwork

Original artwork generated with the built-in imagegen tool on 8 September 2026 for the approved B direction. The concept board was a style reference, not an edit target. Generated sources are retained in this directory. The responsive WebP assets and original vector nine-slice frames are built by `node scripts/pixel-palace-assets.mjs` into `web/public/art/pixel-palace`.

The scenery and illustrations are static. They never load a 3D runtime, run a second frame loop, or participate in the game simulation. The three illustrations have transparent alpha. The code-native frames remain sharp and retain a consistent bevel width on different screens.
